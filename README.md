# Data Structure in C language
# 图解C语言数据结构

一套面向 C 语言学习者的完整数据结构课程。以“纸感学习手册”为视觉风格，用 **54 幅原创 SVG 图解**、**36 段 C 代码**、**32 道章节自测**，把抽象的结构关系画成可以看懂、可以复述的画面。

## 课程内容

| 章节 | 主题           | 核心知识点                                                   |
| ---- | -------------- | ------------------------------------------------------------ |
| 01   | 绪论与算法分析 | 逻辑 / 存储结构、ADT、算法特性、大 O、时间 / 空间复杂度      |
| 02   | 线性表         | 顺序表、单链表、双链表、循环链表、静态链表、选型对比         |
| 03   | 栈与队列       | 顺序栈、链栈、共享栈、循环队列、链队列、括号匹配、表达式、BFS |
| 04   | 串与 KMP       | 串的存储、朴素匹配、π 数组、next / nextval、失配移动         |
| 05   | 树与二叉树     | 树术语、二叉树性质、存储、四种遍历、构造、线索、森林转换、哈夫曼、并查集 |
| 06   | 图             | 图术语、邻接矩阵 / 邻接表、BFS / DFS、Prim、Kruskal、Dijkstra、Floyd、拓扑排序、关键路径 |
| 07   | 查找           | ASL、顺序 / 折半 / 分块、BST、AVL 旋转、红黑树、B 树 / B+ 树、哈希冲突 |
| 08   | 排序           | 插入、希尔、冒泡、快排、选择、堆排、归并、计数、基数、外部排序、总表 |
| 09   | 综合实战       | 结构选型、手写模板、高频错误、三周复习路线、数组 / 矩阵压缩 / 广义表、结课自测 |

全课程共 **9 章、56 节、54 幅图、36 段代码、32 道自测题**。内容覆盖本科《数据结构》与考研 408 的核心大纲；数组、特殊矩阵、广义表作为第 9 章补充。文件结构、网络流、后缀数组等更专门的专题不在本课程范围内。

## 功能

- **章节目录与深链**：左侧目录、上一章 / 下一章、URL hash 直达章节。
- **学习进度**：每章底部可标记完成，进度保存在浏览器 `localStorage`，首页“继续学习”自动定位下一章。
- **全局搜索**：按 `/` 或 `Ctrl/Cmd + K`，检索章节、节标题和知识点。
- **代码高亮与复制**：36 段 C 代码均带复制按钮；代码在构建时自动转义，`<`、`>`、`&` 不会破坏页面。
- **即时自测**：点击选项立即判分并显示解析。
- **打印 / PDF**：右上角打印按钮会隐藏侧栏与交互元素，展开全部章节，适合打印成复习讲义。
- **响应式**：手机端自动收起侧栏，使用抽屉式目录；图形可横向滚动。

## 重新构建

修改 `src/` 或 `assets/` 后，在课程目录运行：

```bash
python build.py
```

脚本会按顺序拼接 10 个片段，把 `<pre><code>` 中的原始 C 代码做 HTML 转义，再写入 `index.html`。Linux / macOS 的 `python3` 也可用。

## 使用建议

1. **先读图**：每节先看图形，用自己的话复述“谁指向谁、谁先谁后”。
2. **再手敲代码**：不要只复制。重点默写链表指针顺序、循环队列边界、递归终止条件。
3. **用自测暴露盲区**：做错后回到对应图，而不是回到大段文字。
4. **按三周路线复习**：线性 → 非线性 → 查找排序，每周输出一张白纸总结。

## 设计说明

- 字体使用系统字体栈（微软雅黑 / 宋体 / 等宽字体），不依赖外部字体。
- 所有图形由 `assets/figures.js` 中的原生 SVG 函数生成，无图片文件、无第三方图表库。
- 配色以纸色、墨色、青绿、赭石为主；代码块使用深墨绿底色，保证打印与屏幕阅读的对比度。
- 打印样式会强制展开所有章节，并对图、代码块、表格做 `break-inside: avoid`。

课程内容与图形均为本项目原创生成，可自由用于个人学习与教学。
