CHAPTER 01 FOUNDATION

绪论：数据结构到底在学研究什么？

写程序不只是“把功能跑通”。同样的功能，用数组还是链表、用循环还是递归，代价可能差几个数量级。 这一章先建立三个共同语言：逻辑结构、存储结构和复杂度。

学完你应该能

  • 区分数据的逻辑结构与存储结构，并各举三个例子
  • 用自己的话解释抽象数据类型（ADT）以及它和 C 结构体的关系
  • 对一段循环 / 递归代码写出时间复杂度与空间复杂度
  • 判断 O(1)、O(log n)、O(n)、O(n log n)、O(n²) 的增长差异
  • 关键词：数据、元素、关系、ADT、大 O、最好 / 最坏 / 平均情况
  • 常见误区：把“逻辑结构”当成“内存布局”

1.1数据、元素与结构

数据是信息的载体，所有能输入计算机并被程序处理的符号都算数据。 数据的基本单位叫数据元素，一个元素通常由若干数据项组成。 例如一条学生记录是一个元素，学号、姓名、成绩是数据项。

仅有元素还不够。数据结构研究的是元素之间有什么关系，以及在这些关系上能做什么操作。 所以一个数据结构通常包含三部分：逻辑结构、存储结构、运算。

一句话定义

数据结构是相互之间存在一种或多种特定关系的数据元素的集合，以及定义在该集合上的一组操作。

逻辑结构：元素之间的抽象关系

  • 集合：元素同属一个集合，彼此没有次序或层次关系。
  • 线性结构：一对一，除首尾外每个元素有唯一前驱和唯一后继。线性表、栈、队列、串都属于此类。
  • 树形结构：一对多，有唯一的根，元素之间存在层次关系。
  • 图状结构：多对多，任意两个元素之间都可能有关系。

存储结构：关系在内存里怎么落地

逻辑结构是“设计图”，存储结构是“施工方案”。同一种逻辑结构，可以用不同方式存进内存， 操作的难度和代价也随之改变。

存储方式核心手段优点代价
顺序存储连续内存 + 下标随机访问 O(1)，缓存友好插入删除移动元素，容量固定
链式存储结点 + 指针插入删除灵活，按需分配指针额外空间，不能随机访问
索引存储索引表（关键字 → 地址）按关键字检索快索引表占空间，维护成本高
散列存储哈希函数直接算地址理想情况下 O(1) 查找冲突处理复杂，不保持顺序

1.2抽象数据类型：先约定“能做什么”

抽象数据类型（ADT）把“数据长什么样”和“能做什么操作”打包成一个逻辑概念， 但不规定内部怎么实现。它像一个合同：使用者只关心接口，实现者可以自由选择数组或链表。

ADT = (D, S, P) D 数据对象，S 关系，P 操作集合

以“线性表”为例，它的 ADT 只约定：元素排成一条线，支持初始化、求长度、按位查找、插入、删除等操作。 至于底层用数组还是链表，是后续实现阶段的事。

ADT List / 概念接口（C 风格伪代码）

ADT List {
    Data:
        线性序列 a1, a2, ..., an，n >= 0
    Operation:
        InitList(&L)          // 构造空表
        Length(L)             // 返回元素个数
        GetElem(L, i, &e)     // 取第 i 个元素
        LocateElem(L, e)      // 查找元素 e 的位置
        ListInsert(&L, i, e)  // 在第 i 个位置插入
        ListDelete(&L, i, &e) // 删除第 i 个元素并返回
        DestroyList(&L)       // 销毁表
} ADT List

在 C 里，ADT 通常由两部分落地：结构体描述数据，一组函数描述操作。 结构体可以公开，也可以藏在 .c 文件里，只暴露函数声明。

SqList.h / 顺序表的数据与接口

#define MaxSize 50
typedef int ElemType;

typedef struct {
    ElemType data[MaxSize];  // 静态分配
    int length;              // 当前元素个数
} SqList;

void InitList(SqList *L);
int  Length(const SqList *L);
int  GetElem(const SqList *L, int i, ElemType *e);
int  ListInsert(SqList *L, int i, ElemType e);
int  ListDelete(SqList *L, int i, ElemType *e);
为什么先讲 ADT？

因为它迫使你把“接口”和“实现”分开。考试里问“顺序表和链表的区别”，本质就是在比较同一个 ADT 的两种实现。

1.3算法：五个特性与好坏标准

算法是解决特定问题的有限步骤序列。注意它不等于程序：程序可以用某种语言写出来并在机器上运行， 算法则是解决问题的思路；同一个算法可以用不同语言实现。

算法的五个特性

  • 有穷性：执行有限步后结束，每一步也在有限时间内完成。
  • 确定性：每条指令含义明确，相同输入得到相同输出，不能有歧义。
  • 可行性：每一步都可以通过有限次基本运算实现。
  • 输入：有零个或多个输入。
  • 输出：至少有一个输出，否则算法没有意义。

评价一个算法，通常看四点：正确性（能解决问题）、可读性（人容易懂）、 健壮性（非法输入不会崩）、效率（时间与空间开销低）。 前三点决定“能不能用”，效率决定“好不好用”。

记忆口诀

“有确可输输”——有穷、确定、可行、输入、输出。考试选择题常把“可读性”混进来，它属于好算法标准，不是五特性。

1.4时间复杂度：只看增长的量级

我们不可能精确统计每条机器指令耗时，所以用基本操作执行次数随问题规模 n 的增长趋势来衡量效率， 这就是时间复杂度。大 O 记号只保留最高阶项，并忽略常数系数。

T(n) = 3n² + 5n + 7 = O(n²) 只保留最高阶，去掉系数与低阶项

例如 3n² + 5n + 7，当 n 很大时 n² 项占绝对主导，所以记作 O(n²)。 常数阶写作 O(1)，即使循环执行了 100 次，只要次数与 n 无关，仍是 O(1)。

三步分析法

  1. 找基本操作：最内层、执行最频繁的那条语句。
  2. 数执行次数：用 n 表示，写出求和式。
  3. 取最高阶：去掉常数和低阶项，得到 O(f(n))。
complexity.c / 三个典型循环

// ① 线性：循环 n 次
int sum(int n) {
    int s = 0;
    for (int i = 1; i <= n; i++)
        s += i;
    return s;
}   // T(n) = O(n)

// ② 对数：i 每次乘 2，很快超过 n
int count(int n) {
    int c = 0;
    for (int i = 1; i < n; i *= 2)
        c++;
    return c;
}   // T(n) = O(log n)

// ③ 平方：两层都从 1 到 n
void pairs(int n) {
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++)
            printf("%d,%d\n", i, j);
}   // T(n) = O(n²)

如果内层循环依赖外层，例如 for (j = 1; j <= i; j++)，总次数是 1 + 2 + … + n = n(n+1)/2，仍然是 O(n²)。

最好、最坏与平均

同一个算法，输入不同，执行次数可能不同。顺序查找找第一个元素只要 1 次，找最后一个要 n 次。 一般用最坏时间复杂度作为保证，用平均时间复杂度描述典型表现。

复杂度典型场景n 翻倍时直觉
O(1)数组下标访问、哈希理想查找不变一步到位
O(log n)折半查找、平衡树查找只多 1 次每次砍一半
O(n)遍历数组 / 链表约 2 倍每个元素看一遍
O(n log n)归并排序、堆排序、快排平均约 2 倍多一点分治 + 线性合并
O(n²)冒泡、插入、选择排序约 4 倍两两比较
O(2ⁿ)子集枚举、朴素递归平方级增长组合爆炸

空间复杂度

空间复杂度衡量算法额外占用的存储随 n 的增长，记作 S(n)。只统计辅助空间， 不统计输入数据本身。原地排序通常 S(n)=O(1)；归并排序需要辅助数组，S(n)=O(n)； 递归算法还要算调用栈，深度为 h 的递归通常 S(n)=O(h)。

两个常见坑

① O(1) 不代表“只执行一次”，而是执行次数与 n 无关。② 递归代码的空间复杂度不能只看局部变量，递归栈也要算。

线性表：最常用，也最容易写错指针

线性表是 n 个同类型元素的有限序列。它只有两种经典实现：顺序表用连续内存， 链表用指针串联。所有后续的栈、队列、串，都可以看作受限的线性表。

学完你应该能

  • 写出顺序表的插入、删除，并分析移动次数
  • 手写单链表的建表、查找、插入、删除与原地逆置
  • 说清双链表插入删除时每个指针的修改顺序
  • 在具体场景中选择顺序表或链表，并说明理由
  • 关键词：头结点、首元结点、前驱、后继、随机访问、静态链表
  • 常见误区：free 之后继续访问、插入时先断后路、循环链表判空

2.1线性表的定义与 ADT

线性表是 n（n ≥ 0）个相同类型数据元素的有限序列，记作 (a₁, a₂, …, aₙ)。 n=0 时叫空表。除第一个元素外，每个元素有且仅有一个直接前驱；除最后一个元素外， 每个元素有且仅有一个直接后继。

a₁ → a₂ → a₃ → … → aₙ 一对一，首尾例外

线性表支持按位查找、按值查找、插入、删除、求长度、遍历等操作。注意“位序”通常从 1 开始， 而 C 数组下标从 0 开始，写代码时最容易在这里差一。

逻辑与存储分开看

“线性表”是逻辑结构；顺序表和链表是它的两种存储实现。考试问“线性表能否随机访问”，答案取决于实现方式，不能一概而论。

2.2顺序表：连续内存带来的快与慢

顺序表用一组地址连续的存储单元依次存放元素，通常用数组加一个 length 变量表示。 因为地址连续，第 i 个元素的地址可以直接算出来，所以支持随机访问。

LOC(aᵢ) = LOC(a₀) + i × sizeof(ElemType) 下标从 0 开始

插入与删除为什么要移动元素

数组的物理位置是固定的。要在中间插入一个元素，必须把后面的元素依次后移，腾出空位； 删除则相反，要把后面的元素依次前移，填补空洞。

在长度为 n 的表里，等概率插入到第 i 个位置，平均移动 n/2 个元素；删除平均移动 (n−1)/2 个。 因此插入、删除的时间复杂度都是 O(n)。但在表尾插入 / 删除是 O(1)。

SqList.c / 初始化、插入、删除

#include <stdio.h>
#define MaxSize 50
typedef int ElemType;

typedef struct {
    ElemType data[MaxSize];
    int length;
} SqList;

void InitList(SqList *L) {
    L->length = 0;
}

// 在位序 i（1..length+1）插入 e
int ListInsert(SqList *L, int i, ElemType e) {
    if (i < 1 || i > L->length + 1) return 0;  // 位序非法
    if (L->length >= MaxSize) return 0;        // 表满

    for (int j = L->length; j >= i; j--)
        L->data[j] = L->data[j - 1];           // 从后往前后移

    L->data[i - 1] = e;
    L->length++;
    return 1;
}

// 删除位序 i，用 e 带回被删元素
int ListDelete(SqList *L, int i, ElemType *e) {
    if (i < 1 || i > L->length) return 0;

    *e = L->data[i - 1];
    for (int j = i; j < L->length; j++)
        L->data[j - 1] = L->data[j];           // 从前往后依次前移

    L->length--;
    return 1;
}

int main(void) {
    SqList L;
    InitList(&L);
    for (int i = 1; i <= 5; i++) ListInsert(&L, i, i * 10);

    ElemType x;
    ListDelete(&L, 3, &x);
    printf("deleted=%d, length=%d\n", x, L.length);
    return 0;
}
动态顺序表

静态数组容量固定。工程中常用 malloc 申请动态数组，满时按 1.5 或 2 倍扩容，再把旧数据搬过去。单次扩容 O(n)，但均摊到每次插入仍是 O(1)。

2.3单链表：用指针把结点串起来

链表把每个元素放在独立的结点里，结点包含数据域和指针域。 逻辑上相邻的元素，物理上可以相隔很远，靠指针建立联系。第一个结点叫首元结点。

带头结点有两个好处：一是空表和非空表的处理统一；二是在表头插入 / 删除时不必修改头指针本身。 代价是多占一个结点的空间。

插入：先接后路，再断前路

在结点 p 之后插入 s，必须先把 s 的 next 指向 p 原来的后继，再让 p 的 next 指向 s。 如果顺序反过来，p 原来的后继就丢了。

删除：绕过再释放

LinkList.c / 头插建表、插入、删除、逆置

#include <stdio.h>
#include <stdlib.h>

typedef int ElemType;
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;

// 带头结点，头插法建表（输入顺序与表中顺序相反）
LinkList List_HeadInsert(void) {
    LinkList L = (LNode *)malloc(sizeof(LNode));
    L->next = NULL;

    ElemType x;
    while (scanf("%d", &x) == 1 && x != 9999) {
        LNode *s = (LNode *)malloc(sizeof(LNode));
        s->data = x;
        s->next = L->next;
        L->next = s;
    }
    return L;
}

// 在位序 i 插入 e
int ListInsert(LinkList L, int i, ElemType e) {
    if (i < 1) return 0;
    LNode *p = L;
    int j = 0;
    while (p != NULL && j < i - 1) {  // 找到第 i-1 个结点
        p = p->next;
        j++;
    }
    if (p == NULL) return 0;

    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->data = e;
    s->next = p->next;   // ① 先接后
    p->next = s;         // ② 再断前
    return 1;
}

// 删除位序 i，返回是否成功
int ListDelete(LinkList L, int i, ElemType *e) {
    if (i < 1) return 0;
    LNode *p = L, *q;
    int j = 0;
    while (p != NULL && j < i - 1) {
        p = p->next;
        j++;
    }
    if (p == NULL || p->next == NULL) return 0;

    q = p->next;
    p->next = q->next;
    *e = q->data;
    free(q);
    return 1;
}

// 原地逆置（不申请新结点）
void Reverse(LinkList L) {
    LNode *pre = NULL, *cur = L->next, *nxt;
    while (cur != NULL) {
        nxt = cur->next;
        cur->next = pre;
        pre = cur;
        cur = nxt;
    }
    L->next = pre;
}

void Print(LinkList L) {
    for (LNode *p = L->next; p; p = p->next)
        printf("%d ", p->data);
    printf("\n");
}

int main(void) {
    LinkList L = List_HeadInsert();
    ListInsert(L, 2, 100);
    ElemType x;
    ListDelete(L, 1, &x);
    Reverse(L);
    Print(L);
    return 0;
}
三个高频错误

① 插入时先执行 p->next = s，丢了后继。② 删除后先 free 再读 q->next。③ 遍历条件写成 p->next != NULL，漏掉最后一个结点。

2.4双链表与循环链表

单链表只能单向走，找前驱要从头再来。双链表在每个结点加一个 prior 指针，可以双向移动； 循环链表让尾结点指回头结点，形成环，从任意结点都能走遍全表。

双链表在 p 之后插入 s 的标准顺序：先让 s 的 prior、next 接好，再改后继的 prior，最后改 p 的 next。 任何一步提前覆盖，都可能丢失原来的链。

DLinkList.c / 双链表插入与删除

typedef struct DNode {
    ElemType data;
    struct DNode *prior, *next;
} DNode, *DLinkList;

// 在 p 之后插入 s
int InsertAfter(DNode *p, DNode *s) {
    if (p == NULL || s == NULL) return 0;

    s->prior = p;
    s->next = p->next;
    if (p->next != NULL)
        p->next->prior = s;
    p->next = s;
    return 1;
}

// 删除 p 的后继结点
int DeleteAfter(DNode *p, ElemType *e) {
    if (p == NULL || p->next == NULL) return 0;

    DNode *q = p->next;
    p->next = q->next;
    if (q->next != NULL)
        q->next->prior = p;
    *e = q->data;
    free(q);
    return 1;
}

// 带头结点的双向循环链表：判空、找尾
int IsEmpty(DLinkList L) {
    return L->next == L;      // 循环：空表指向自己
}

DNode *GetTail(DLinkList L) {
    return L->prior;          // 尾结点 = 头结点的前驱，O(1)
}
循环链表的实用技巧

只设尾指针 rear 而不设头指针，可以 O(1) 找到表头（rear->next）和表尾（rear），合并两个循环链表也很方便。

2.5静态链表：用数组模拟指针

在没有指针的语言里，可以用数组实现链表：每个数组元素存 data 和 next，next 存的是下一个元素的下标， 而不是地址。这种结构叫静态链表。

StaticList.c / 数组里的链表

#define MaxSize 100
typedef int ElemType;

typedef struct {
    ElemType data;
    int next;      // 下一个元素的下标
} SLinkList[MaxSize];

// 初始化：0 号位为头结点，next = -1 表示空
void InitList(SLinkList L) {
    for (int i = 0; i < MaxSize; i++) {
        L[i].next = -1;
        L[i].data = 0;
    }
}

// 遍历
void Print(SLinkList L) {
    for (int p = L[0].next; p != -1; p = L[p].next)
        printf("%d ", L[p].data);
    printf("\n");
}

静态链表适合容量可预估、又不方便动态分配的场景。它保留了链表“插入删除不移动元素”的优点， 但失去了顺序表“按下标 O(1) 访问”的能力——因为逻辑相邻的下标不一定相邻。

2.6顺序表 vs 链表：怎么选

  • 读多写少，经常按下标访问
  • 数据量可预估，内存充足
  • 需要缓存友好、遍历快
  • 只在尾部增删（动态数组）

  • 频繁在中间插入、删除
  • 元素数量变化大，难以预估
  • 需要把大对象分散存放

顺序表赢在“随机访问”，链表赢在“局部改动”。先用操作频率做判断，再考虑缓存和内存碎片。

栈与队列：限制反而带来力量

3.1栈：只在一端操作

栈是只允许在一端进行插入和删除的线性表。允许操作的一端叫栈顶， 另一端叫栈底。元素遵循后进先出（LIFO）：最后进去的最先出来。

顺序栈用数组加一个 top 下标实现。压栈、弹栈、取栈顶都是 O(1)。 需要检查两种异常：栈满时继续入栈叫上溢，空栈时继续出栈叫下溢。

SqStack.c / 顺序栈

#include <stdio.h>
#define MaxSize 50
typedef int ElemType;

typedef struct {
    ElemType data[MaxSize];
    int top;              // 栈顶下标，空栈为 -1
} SqStack;

void InitStack(SqStack *S) {
    S->top = -1;
}

int StackEmpty(const SqStack *S) {
    return S->top == -1;
}

int Push(SqStack *S, ElemType x) {
    if (S->top == MaxSize - 1) return 0;   // 上溢
    S->data[++S->top] = x;
    return 1;
}

int Pop(SqStack *S, ElemType *x) {
    if (S->top == -1) return 0;            // 下溢
    *x = S->data[S->top--];
    return 1;
}

int GetTop(const SqStack *S, ElemType *x) {
    if (S->top == -1) return 0;
    *x = S->data[S->top];
    return 1;
}
top 的两种约定

有的教材让 top 指向“栈顶元素”，空栈为 −1；有的让 top 指向“下一个可写位置”，空栈为 0。两种写法都能用，但入栈、出栈、判空的表达式必须配套，不能混用。

3.2链栈与共享栈

链栈用单链表实现，通常让栈顶放在链表头部：入栈就是头插，出栈就是删除首元结点，都是 O(1)。 因为只在头部操作，链栈不需要头结点也能写得很简洁。

LinkStack.c / 链栈

typedef struct SNode {
    ElemType data;
    struct SNode *next;
} SNode, *LinkStack;

void InitStack(LinkStack *S) {
    *S = NULL;                 // 空栈
}

int Push(LinkStack *S, ElemType x) {
    SNode *s = (SNode *)malloc(sizeof(SNode));
    if (s == NULL) return 0;
    s->data = x;
    s->next = *S;
    *S = s;                    // 新结点成为栈顶
    return 1;
}

int Pop(LinkStack *S, ElemType *x) {
    if (*S == NULL) return 0;
    SNode *p = *S;
    *x = p->data;
    *S = p->next;
    free(p);
    return 1;
}

共享栈：两个栈共用一个数组

如果两个栈的空间需求此消彼长，可以让它们从数组两端向中间生长：0 号栈从左往右，1 号栈从右往左。 只有两个栈顶相遇时才真正溢出，空间利用率更高。

3.3栈的经典应用

括号匹配

从左到右扫描表达式：遇到左括号就入栈；遇到右括号就弹出栈顶，看类型是否匹配。 扫描结束后栈必须为空。任何一步“栈空却遇到右括号”或“类型不匹配”，都说明括号不合法。

bracket.c / 括号匹配

#include <stdio.h>
#include <string.h>

#define MaxSize 100

int Match(const char *s) {
    char stack[MaxSize];
    int top = -1;

    for (int i = 0; s[i] != '\0'; i++) {
        char c = s[i];
        if (c == '(' || c == '[' || c == '{') {
            if (top == MaxSize - 1) return 0;
            stack[++top] = c;
        } else if (c == ')' || c == ']' || c == '}') {
            if (top == -1) return 0;       // 右括号多余
            char left = stack[top--];
            if ((c == ')' && left != '(') ||
                (c == ']' && left != '[') ||
                (c == '}' && left != '{'))
                return 0;                  // 类型不匹配
        }
    }
    return top == -1;                      // 左括号是否全部配完
}

int main(void) {
    printf("%d\n", Match("{[()]}"));       // 1
    printf("%d\n", Match("([)]"));         // 0
    return 0;
}

表达式求值

人类习惯中缀表达式 (A+B)*C-D，计算机更喜欢后缀表达式 A B + C * D -。后缀表达式没有括号，运算符出现的顺序就是计算顺序。

中缀转后缀的规则

操作数直接输出；运算符入栈前，先把栈顶优先级 ≥ 它的运算符弹出；左括号直接入栈；遇到右括号，弹出到左括号为止。最后把栈中剩余运算符全部弹出。

递归与函数调用

递归本质上是系统用栈保存每次调用的返回地址、参数和局部变量。递归太深会栈溢出， 因为调用栈的空间有限。把递归改写成显式栈，往往能更好地控制内存。

3.4队列：一端进，另一端出

队列只允许在队尾插入、在队头删除，遵循先进先出（FIFO）。 想象排队买饭：先来的人先打到饭，后来的人站在队尾。

用普通数组实现队列时，front 和 rear 都只能往后走，前面出队留下的空位无法复用， 最终 rear 到达数组末尾，但数组前部还有空间，这叫假溢出。 解决办法是把数组“首尾相接”，做成循环队列。

SqQueue.c / 循环队列

#define MaxSize 10
typedef int ElemType;

typedef struct {
    ElemType data[MaxSize];
    int front;      // 队头元素下标
    int rear;       // 队尾元素的下一个位置
} SqQueue;

void InitQueue(SqQueue *Q) {
    Q->front = Q->rear = 0;
}

int QueueEmpty(const SqQueue *Q) {
    return Q->front == Q->rear;
}

int QueueLength(const SqQueue *Q) {
    return (Q->rear - Q->front + MaxSize) % MaxSize;
}

int EnQueue(SqQueue *Q, ElemType x) {
    if ((Q->rear + 1) % MaxSize == Q->front) return 0;  // 队满
    Q->data[Q->rear] = x;
    Q->rear = (Q->rear + 1) % MaxSize;
    return 1;
}

int DeQueue(SqQueue *Q, ElemType *x) {
    if (Q->front == Q->rear) return 0;                  // 队空
    *x = Q->data[Q->front];
    Q->front = (Q->front + 1) % MaxSize;
    return 1;
}
三个公式一起记

队空：front == rear。队满：(rear+1)%M == front。长度：(rear−front+M)%M。三个式子都围绕“循环”与“牺牲一格”展开。

3.5链队列与双端队列

链队列用链表实现，队头在链表头部，队尾在链表尾部。入队就是在尾部插入，出队就是删除首元结点。 需要同时维护 front 和 rear 两个指针。

LinkQueue.c / 带头结点的链队列

#include <stdlib.h>

typedef struct LinkNode {
    ElemType data;
    struct LinkNode *next;
} LinkNode;

typedef struct {
    LinkNode *front, *rear;
} LinkQueue;

void InitQueue(LinkQueue *Q) {
    Q->front = Q->rear = (LinkNode *)malloc(sizeof(LinkNode));
    Q->front->next = NULL;
}

int QueueEmpty(const LinkQueue *Q) {
    return Q->front == Q->rear;
}

void EnQueue(LinkQueue *Q, ElemType x) {
    LinkNode *s = (LinkNode *)malloc(sizeof(LinkNode));
    s->data = x;
    s->next = NULL;
    Q->rear->next = s;
    Q->rear = s;
}

int DeQueue(LinkQueue *Q, ElemType *x) {
    if (Q->front == Q->rear) return 0;

    LinkNode *p = Q->front->next;
    *x = p->data;
    Q->front->next = p->next;

    if (Q->rear == p)          // 删除的是最后一个结点
        Q->rear = Q->front;
    free(p);
    return 1;
}

双端队列

双端队列（deque）允许在两端插入和删除。若只允许一端插入、两端删除，叫输入受限双端队列； 反之叫输出受限双端队列。考试常考“哪些输出序列可以由栈 / 双端队列得到”，画图模拟最稳。

3.6应用：BFS 与任务调度

队列最经典的应用是广度优先搜索（BFS）。从起点出发，先把所有距离为 1 的结点入队， 再依次处理，保证按层访问。在无权图中，BFS 第一次到达某点的路径就是最短路径。

bfs.c / 用队列做层序遍历

void BFS(Graph *G, int start, int visited[]) {
    SqQueue Q;
    InitQueue(&Q);

    visited[start] = 1;
    EnQueue(&Q, start);

    while (!QueueEmpty(&Q)) {
        int v;
        DeQueue(&Q, &v);
        visit(v);                       // 处理当前层结点

        for (int w = FirstNeighbor(G, v);
             w >= 0;
             w = NextNeighbor(G, v, w)) {
            if (!visited[w]) {
                visited[w] = 1;         // 入队时标记，防止重复
                EnQueue(&Q, w);
            }
        }
    }
}
为什么入队时就标记 visited？

如果等到出队才标记，同一个结点可能被多个邻居重复入队，队列膨胀。入队即标记，保证每个结点最多进队一次。

其他应用：操作系统中的就绪队列、打印任务队列、消息队列、滑动窗口最大值（单调队列）、 树的层序遍历等。栈则常见于函数调用、撤销操作、浏览器后退、表达式求值、深度优先搜索。

串与 KMP：让主串指针永不回头

串是元素为字符的线性表。模式匹配看起来简单，却藏着数据结构里最优雅的思想之一： 已经匹配过的信息不要浪费。KMP 用一张前缀表，让主串指针只前进、不后退。

4.1串的定义与存储

串是由零个或多个字符组成的有限序列，通常记作 S = "a₁a₂…aₙ"。 零个字符的串叫空串，长度为 0。注意空串和空格串不同：空格也是字符。

串的逻辑结构和线性表相同，区别在于每个元素只能是字符，并且经常把“一整个串”作为操作对象， 例如求子串、比较、拼接、模式匹配。

存储方式结构优点缺点
定长顺序存储字符数组 + 长度简单、随机访问长度固定，超长需截断
堆分配存储malloc 一块连续空间长度可动态调整需要手动管理内存
块链存储每个结点存若干字符 + next插入删除灵活指针开销，随机访问差
SString.h / 定长顺序串（1 基下标）

#define MAXLEN 255

typedef struct {
    char ch[MAXLEN + 1];   // ch[1..length] 存字符，ch[0] 不用
    int length;
} SString;

// 由 C 字符串构造，注意长度不能超过 MAXLEN
int StrAssign(SString *T, const char *chars) {
    int len = 0;
    while (chars[len] != '\0') len++;
    if (len > MAXLEN) return 0;

    T->length = len;
    for (int i = 1; i <= len; i++)
        T->ch[i] = chars[i - 1];
    return 1;
}

许多教材采用 1 基下标，是为了让 next 数组的下标和“第几个字符”一致，写起来更直观。 C 语言本身是 0 基，工程代码里也可以统一用 0 基，只要全程一致即可。

4.2朴素匹配：为什么会慢

模式匹配要回答：模式串 T 是否在主串 S 中出现？出现的位置是哪里？ 朴素算法（BF）的思路是：从 S 的每个位置开始，逐个字符与 T 比较；一旦失配， 主串指针回到本趟起点的下一个位置，模式串指针回到开头，重新比较。

naive.c / 朴素模式匹配

// 返回模式串 T 在主串 S 中第一次出现的位置（1 基），失败返回 0
int Index_BF(SString S, SString T) {
    int i = 1, j = 1;

    while (i <= S.length && j <= T.length) {
        if (S.ch[i] == T.ch[j]) {
            ++i;
            ++j;
        } else {
            i = i - j + 2;   // 回到本趟起点的下一个位置

    return 0;

4.3KMP：利用“已经匹配”的信息

观察失配瞬间：模式串的前 j−1 个字符已经和主串匹配。如果这 j−1 个字符的某个前缀 恰好等于某个后缀，那么我们可以把模式串整体右移，让这个前缀对准后缀， 继续比较，而不必回退主串指针。

核心概念：最长相等真前缀与真后缀

“真”表示不能取整个子串本身。π[i] 就是子串 P[0..i] 的最长相等真前缀与真后缀的长度。它衡量的是“失配后能复用多少已匹配信息”。

// 求模式串 T 的 next 数组（1 基）
void GetNext(SString T, int next[]) {
    int i = 1, j = 0;
    next[1] = 0;

    while (i < T.length) {
        if (j == 0 || T.ch[i] == T.ch[j]) {
            ++i;
            ++j;
            next[i] = j;
        } else {
            j = next[j];       // 退而求其次，找更短的前缀
        }
    }
}

// KMP 匹配，返回 1 基位置，失败返回 0
int Index_KMP(SString S, SString T, int next[]) {
    int i = 1, j = 1;

    while (i <= S.length && j <= T.length) {
        if (j == 0 || S.ch[i] == T.ch[j]) {
            ++i;
            ++j;
        } else {
            j = next[j];       // 只回退模式串，主串不回退
        }
    }

    if (j > T.length) return i - T.length;
    return 0;
}

KMP 的时间复杂度是 O(n + m)：求 next 是 O(m)，匹配是 O(n)，因为 i 从不减小。 空间复杂度 O(m)，用来存 next 数组。

4.4nextval：跳过无意义的比较

如果失配时，回退后的字符和当前失配字符相同，那么这次比较一定还会失败。 例如模式串 "aaaab"，在某个 a 上失配后回退到另一个 a，仍然会失配。 nextval 把这些“必然失败”的回退直接跳过。

nextval.c / 优化 next

void GetNextval(SString T, int nextval[]) {
    int i = 1, j = 0;
    nextval[1] = 0;

    while (i < T.length) {
        if (j == 0 || T.ch[i] == T.ch[j]) {
            ++i;
            ++j;

            if (T.ch[i] != T.ch[j])
                nextval[i] = j;          // 回退后字符不同，保留
            else
                nextval[i] = nextval[j]; // 相同，继续往前跳
        } else {
            j = nextval[j];
        }
    }
}

5.1树的基本术语

树是 n（n ≥ 0）个结点的有限集合。n=0 时是空树；n>0 时有且仅有一个根结点， 其余结点可以分成若干互不相交的有限集，每个集合又是一棵子树。

5.2二叉树：五种形态与五条性质

二叉树是每个结点最多有两棵子树的树，且左右子树有次序之分。 即使只有一个孩子，也要区分它是左孩子还是右孩子。

五条常用性质

  1. 第 i 层最多有 2i−1 个结点（根为第 1 层）。
  2. 深度为 h 的二叉树最多有 2h − 1 个结点。
  3. 叶结点数 n₀ 与度为 2 的结点数 n₂ 满足 n₀ = n₂ + 1。
  4. n 个结点的完全二叉树高度为 ⌈log₂(n+1)⌉ 或 ⌊log₂n⌋ + 1。
  5. 完全二叉树按层序从 1 编号：左孩子 2i，右孩子 2i+1，双亲 ⌊i/2⌋。
n₀ = n₂ + 1 怎么来的？

设结点总数 n = n₀ + n₁ + n₂，边数 = n − 1。每个结点（除根）都有一条边连向双亲，而边也等于 n₁ + 2n₂。联立得 n₀ + n₁ + n₂ − 1 = n₁ + 2n₂，化简即 n₀ = n₂ + 1。

5.3二叉树的存储结构

顺序存储把结点按完全二叉树的编号放进数组。对完全二叉树来说非常紧凑； 但对一般二叉树，空结点也要占位，极端情况下（只有右孩子的单链）会浪费大量空间。

BiTree.h / 二叉链表定义

typedef char ElemType;

typedef struct BiTNode {
    ElemType data;

// 创建一个新结点

5.4四种遍历：访问每个结点一次

遍历是按某条搜索路线访问每个结点且只访问一次。二叉树的递归定义决定了三种深度优先遍历： 前序（根左右）、中序（左根右）、后序（左右根）。层序则按层从左到右访问。

traverse.c / 递归遍历与非递归中序

void PreOrder(BiTree T) {
    if (T != NULL) {
        printf("%c ", T->data);
        PreOrder(T->lchild);
        PreOrder(T->rchild);
    }
}

void InOrder(BiTree T) {
    if (T != NULL) {
        InOrder(T->lchild);
        printf("%c ", T->data);
        InOrder(T->rchild);
    }
}

void PostOrder(BiTree T) {
    if (T != NULL) {
        PostOrder(T->lchild);
        PostOrder(T->rchild);
        printf("%c ", T->data);
    }

// 非递归中序：用栈模拟递归
#define MAXTREE 1000   // 示意容量；工程中可按实际结点数分配
void InOrderIter(BiTree T) {
    BiTree stack[MAXTREE];
    int top = -1;
    BiTree p = T;

    while (p != NULL || top != -1) {
        if (p != NULL) {
            if (top == MAXTREE - 1) return;  // 防止越界
            stack[++top] = p;   // 一路向左，沿途入栈
            p = p->lchild;
        } else {
            p = stack[top--];   // 弹出并访问
            printf("%c ", p->data);
            p = p->rchild;      // 转向右子树
        }
    }
}

层序遍历借助队列：根入队；每次出队一个结点并访问，然后把它非空的左右孩子依次入队。 这样保证按层、从左到右访问。

level.c / 层序遍历

#define MAXQUEUE 1000  // 示意容量；队列最大宽度不会超过结点总数
void LevelOrder(BiTree T) {
    if (T == NULL) return;

    BiTree queue[MAXQUEUE];
    int front = 0, rear = 0;

    queue[rear++] = T;
    while (front < rear) {
        BiTree p = queue[front++];
        printf("%c ", p->data);

        if (p->lchild != NULL) {
            if (rear == MAXQUEUE) return;
            queue[rear++] = p->lchild;
        }
        if (p->rchild != NULL) {
            if (rear == MAXQUEUE) return;
            queue[rear++] = p->rchild;
        }
    }
}
复杂度

四种遍历都访问每个结点一次，时间 O(n)。递归遍历的空间是递归栈 O(h)，h 为树高；层序遍历的空间是队列 O(w)，w 为最大宽度。最坏情况下 h 和 w 都可能达到 n。

5.5由遍历序列还原二叉树

前序的第一个元素一定是根；在中序中找到这个根，左边就是左子树的所有结点，右边就是右子树。 对左右子树递归执行同样的切分，就能唯一还原整棵树。

build.c / 前序 + 中序建树

// pre[l1..r1] 与 in[l2..r2] 表示当前子树
BiTree Build(char pre[], int l1, int r1,
             char in[], int l2, int r2) {
    if (l1 > r1) return NULL;

    int k = l2;
    while (k <= r2 && in[k] != pre[l1]) k++;  // 在中序中定位根
    if (k > r2) return NULL;                  // 序列不匹配，避免越界

    BiTree root = (BiTree)malloc(sizeof(BiTNode));
    root->data = pre[l1];              // 前序第一个是根
    int leftLen = k - l2;              // 左子树结点数

    root->lchild = Build(pre, l1 + 1, l1 + leftLen,
                         in, l2, k - 1);
    root->rchild = Build(pre, l1 + leftLen + 1, r1,
                         in, k + 1, r2);
    return root;
}
组合能否唯一确定说明
前序 + 中序能前序定根，中序分左右
后序 + 中序能后序最后一个定根
层序 + 中序能层序逐个定根，中序分左右
前序 + 后序不能无法区分只有一个孩子时的左右

5.6线索二叉树：把空指针利用起来

二叉链表有 n+1 个空指针域。线索化把这些空指针改造成指向前驱或后继的线索， 并增加 ltag、rtag 两个标志位区分“孩子”还是“线索”。

thread.c / 线索结点与后继查找

typedef struct ThreadNode {
    ElemType data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;      // 1 表示线索，0 表示孩子
} ThreadNode, *ThreadTree;

// 中序第一个结点：从当前结点一路向左
ThreadNode *FirstNode(ThreadNode *p) {
    while (p != NULL && p->ltag == 0)
        p = p->lchild;
    return p;
}

// 中序后继
ThreadNode *NextNode(ThreadNode *p) {
    if (p->rtag == 0)
        return FirstNode(p->rchild);  // 右子树最左下
    return p->rchild;                 // 直接走后继线索
}

线索化的意义是：不需要递归、不需要额外栈，也能高效地找前驱和后继。 代价是每个结点多两个标志位，构建线索需要一次遍历。常见的有前序、中序、后序线索， 其中中序线索最常用。

5.8哈夫曼树与哈夫曼编码

给每个叶子一个权值，构造一棵带权路径长度（WPL）最小的二叉树，就是哈夫曼树。 WPL = Σ(叶子权值 × 叶子深度)。权值越大的叶子应越靠近根。

深度口径要统一

这里的“叶子深度”按根到叶子的边数计算，根的深度为 0。5.1 节讲树的高度时按“根在第 1 层”计，两者相差 1；做 WPL 题时先看题目采用哪种约定，不要混用。

构造方法（贪心）：把所有结点按权值放入集合；每次取出两个权值最小的结点，合并成一个新结点， 权值为两者之和；把新结点放回集合；重复直到只剩一个根。

huffman.c / 结点结构与构造框架

typedef struct {
    int weight;
    int parent, lchild, rchild;   // 数组下标，0 表示空
} HTNode, *HuffmanTree;

// 在 1..n 中选出 parent==0 且权值最小的两个结点
void Select(HuffmanTree HT, int n, int *s1, int *s2);

void CreateHuffmanTree(HuffmanTree HT, int w[], int n) {
    int m = 2 * n - 1;
    for (int i = 1; i <= m; i++) {
        HT[i].parent = HT[i].lchild = HT[i].rchild = 0;
    }
    for (int i = 1; i <= n; i++)
        HT[i].weight = w[i - 1];

    for (int i = n + 1; i <= m; i++) {
        int s1, s2;
        Select(HT, i - 1, &s1, &s2);
        HT[s1].parent = HT[s2].parent = i;
        HT[i].lchild = s1;
        HT[i].rchild = s2;
        HT[i].weight = HT[s1].weight + HT[s2].weight;
    }
}

n 个叶子的哈夫曼树共有 2n−1 个结点，没有度为 1 的结点。哈夫曼编码是前缀编码， 解码时从根出发，遇 0 走左、遇 1 走右，走到叶子就输出一个字符。

5.9并查集：树的另一种用法

并查集（Union-Find）维护一组不相交的集合，只支持两种操作：查找某个元素属于哪个集合， 合并两个集合。它用一棵树表示一个集合，根结点代表集合。

union_find.c / 查找、合并、路径压缩

#define N 100
int parent[N];

void Init(int n) {
    for (int i = 0; i < n; i++) parent[i] = -1;
}

int Find(int x) {
    if (parent[x] < 0) return x;          // 根
    return parent[x] = Find(parent[x]);   // 路径压缩
}

void Union(int a, int b) {
    int ra = Find(a), rb = Find(b);
    if (ra == rb) return;
    parent[rb] = ra;                      // 仅演示挂根，不维护集合大小
}

// 按大小合并，避免树过高；与上面的 Union 二选一，不要混用
void UnionBySize(int a, int b) {
    int ra = Find(a), rb = Find(b);
    if (ra == rb) return;
    if (parent[ra] > parent[rb]) { int t = ra; ra = rb; rb = t; }
    parent[ra] += parent[rb];             // 负数绝对值表示集合大小
    parent[rb] = ra;
}

并查集是 Kruskal 最小生成树的关键组件，也用于判断无向图连通分量、朋友圈合并、等式满足性等问题。 配合按秩合并与路径压缩，单次操作的摊还复杂度接近 O(1)。 注意：上面的简单 Union 不维护集合大小，不能与 UnionBySize 混用； 实际实现建议统一使用按大小 / 按秩合并。

图 G = (V, E)，V 是顶点集合，E 是边集合。边有方向叫有向图，用尖括号 <u,v> 表示； 边无方向叫无向图，用圆括号 (u,v) 表示。

无向图所有顶点度数之和等于边数的 2 倍。因为每条边贡献两个度数。奇度顶点的个数一定是偶数。

6.3BFS 与 DFS：两种走法

图的遍历从某个顶点出发，沿边访问所有可达顶点，每个顶点只访问一次。 因为图可能有环，必须用 visited 数组标记，否则会无限绕圈。

dfs.c / 邻接表的深度优先搜索

int visited[MaxVertexNum];

void DFS(ALGraph *G, int v) {
    visited[v] = 1;
    visit(v);

    for (ArcNode *p = G->vertices[v].firstarc;
         p != NULL;
         p = p->nextarc) {
        int w = p->adjvex;
        if (!visited[w])
            DFS(G, w);
    }
}

// 处理非连通图：每个未访问顶点都启动一次
void DFSTraverse(ALGraph *G) {
    for (int i = 0; i < G->vexnum; i++) visited[i] = 0;
    for (int i = 0; i < G->vexnum; i++)
        if (!visited[i]) DFS(G, i);
}
复杂度与性质

邻接表：O(n+e)；邻接矩阵：O(n²)。BFS 可以求无权图单源最短路；DFS 适合求连通分量、判断环、生成拓扑序。DFS 递归深度最坏为 n。

6.4最小生成树：Prim 与 Kruskal

生成树是包含图中全部 n 个顶点、恰好 n−1 条边的连通子图。带权图的最小生成树（MST） 是所有生成树中边权之和最小的那棵。以下默认讨论无向连通带权图；若图不连通，得到的是最小生成森林。

Prim：从一个点开始“滚雪球”

任选一个起点加入集合 U；每次从“一个端点在 U、另一个端点在 V−U”的边中选权值最小的一条， 把新顶点加入 U；重复 n−1 次。它更像“加点”，适合稠密图。

朴素 Prim 用邻接矩阵实现，时间 O(n²)，与边数无关；用优先队列可做到 O(e log n)。

Kruskal：从最短边开始“挑边”

把所有边按权值从小到大排序；依次考察每条边，如果它连接的两个顶点不在同一个连通分量中， 就加入 MST；否则会成环，跳过。直到选够 n−1 条边。

算法思路时间复杂度适合
Prim加点，扩展生成树O(n²)（朴素）/ O(e log n)稠密图
Kruskal排序边，并查集防环O(e log e)稀疏图

6.5最短路径：Dijkstra 与 Floyd

Dijkstra：单源最短路

维护一个 dist 数组，表示源点到各点的当前最短估计。每轮从未确定的点中选 dist 最小的， 把它“定型”，再用它去松弛邻居：如果 dist[u] + w(u,v) < dist[v]，就更新 dist[v]。

dijkstra.c / 邻接矩阵单源最短路

void Dijkstra(MGraph *G, int src, int dist[], int path[]) {
    int final[MaxVertexNum] = {0};

    for (int i = 0; i < G->vexnum; i++) {
        dist[i] = G->edge[src][i];
        path[i] = (dist[i] < INF) ? src : -1;
    }
    dist[src] = 0;
    final[src] = 1;

    for (int round = 1; round < G->vexnum; round++) {
        int u = -1, best = INF;
        for (int i = 0; i < G->vexnum; i++) {
            if (!final[i] && dist[i] < best) {
                best = dist[i];
                u = i;
            }
        }
        if (u == -1) break;        // 剩余点不可达
        final[u] = 1;

        for (int v = 0; v < G->vexnum; v++) {
            if (!final[v] && G->edge[u][v] < INF &&
                dist[u] + G->edge[u][v] < dist[v]) {
                dist[v] = dist[u] + G->edge[u][v];
                path[v] = u;
            }
        }
    }
}
Dijkstra 的边界

不能处理负权边。因为“当前 dist 最小就定型”的前提是后续路径不会把它变得更小，负权会破坏这个前提。负权图要用 Bellman-Ford 或 SPFA。

Floyd：任意两点间最短路

Floyd 用动态规划：依次允许顶点 k 作为中转站，更新所有点对 (i,j)。 三重循环，代码极短，能处理负权边（但不能有负权回路）。

D[i][j] = min(D[i][j], D[i][k] + D[k][j]) k 从 0 到 n−1 依次作为中转

6.6拓扑排序：给依赖关系排个序

有向无环图（DAG）可以表示任务依赖：边 u→v 表示 u 必须在 v 之前完成。 拓扑排序把所有顶点排成一个线性序列，使每条边都从前指向后。

topo.c / Kahn 拓扑排序

int TopoSort(ALGraph *G, int order[]) {
    int indeg[MaxVertexNum] = {0};
    int queue[MaxVertexNum], front = 0, rear = 0;

    for (int v = 0; v < G->vexnum; v++)
        for (ArcNode *p = G->vertices[v].firstarc; p; p = p->nextarc)
            indeg[p->adjvex]++;

    for (int v = 0; v < G->vexnum; v++)
        if (indeg[v] == 0) queue[rear++] = v;

    int count = 0;
    while (front < rear) {
        int u = queue[front++];
        order[count++] = u;

        for (ArcNode *p = G->vertices[u].firstarc; p; p = p->nextarc) {
            int v = p->adjvex;
            if (--indeg[v] == 0)
                queue[rear++] = v;
        }
    }
    return count == G->vexnum;   // 0 表示有环
}

拓扑序通常不唯一。若同时有多个入度为 0 的顶点，它们的相对顺序可以交换。 也可以用 DFS 的后序逆序得到拓扑序。

6.7关键路径：项目最短工期

AOE 网用边表示活动、顶点表示事件，边权表示活动持续时间。从源点到汇点的最长路径叫关键路径， 它决定整个工程的最短完工时间。

计算分四步：

  1. ve(v)：事件最早发生时间，从源点开始正向递推：ve(v) = max{ ve(u) + w(u,v) }，对所有入边 u→v；源点 ve = 0。
  2. vl(v)：事件最晚发生时间，从汇点开始反向递推：vl(v) = min{ vl(w) − w(v,w) }，对所有出边 v→w；汇点 vl = ve。
  3. e(a) = ve(起点)，l(a) = vl(终点) − 活动时长。
  4. 若 e(a) = l(a)，该活动为关键活动。关键活动都位于至少一条关键路径上；关键路径由关键活动组成，可能不唯一。
为什么是“最长”而不是“最短”？

工程要等所有并行任务都完成。最短路径只考虑一条链，而总工期由最慢的那条依赖链决定，所以取最长路径。

7.1查找与平均查找长度

查找是在数据集合中找出关键字等于给定值的记录。衡量查找算法效率的常用指标是 平均查找长度（ASL）：所有查找过程中关键字比较次数的期望。

ASL = Σ pᵢ × cᵢ pᵢ 是查找第 i 个元素的概率，cᵢ 是比较次数

等概率情况下 pᵢ = 1/n。ASL 分为查找成功和查找失败两种：成功时统计命中元素， 失败时统计走到“空指针 / 失败结点”的比较次数。做题时先确认题目问的是哪一种。

7.2顺序、折半与分块查找

顺序查找从表头逐个比较，不要求有序。成功平均 (n+1)/2 次，失败 n 次，时间复杂度 O(n)。 优点是简单、对存储无要求，链表也能用。

折半查找要求有序且顺序存储。每次取中间元素比较， 相等则命中；目标较小就到左半区，较大就到右半区。每次区间减半，最多约 ⌈log₂(n+1)⌉ 次。

binary_search.c / 折半查找

// 有序数组 a[0..n-1]，返回下标，失败返回 -1
int BinarySearch(const int a[], int n, int key) {
    int low = 0, high = n - 1;

    while (low <= high) {
        int mid = low + (high - low) / 2;  // 防溢出
        if (a[mid] == key)
            return mid;
        else if (a[mid] < key)
            low = mid + 1;
        else
            high = mid - 1;
    }
    return -1;
}

折半查找的判定树是一棵平衡的二叉排序树，树高约 log₂n，所以查找 O(log n)。 但插入 / 删除要维持有序，通常需要 O(n) 移动，因此它适合静态查找表。

分块查找（索引顺序查找）

把表分成若干块，块内无序、块间有序，再建一张索引表记录每块的最大关键字和起始地址。 先查索引确定块，再在块内顺序查找。平均性能介于顺序与折半之间，适合动态变化但不想整体排序的场景。

7.3二叉排序树（BST）

二叉排序树满足：左子树所有结点 < 根 < 右子树所有结点，且左右子树也分别是 BST。 对它做中序遍历，得到的一定是升序序列。

bst.c / 查找、插入、删除

typedef struct BSTNode {
    int key;
    struct BSTNode *lchild, *rchild;
} BSTNode, *BSTree;

BSTNode *BST_Search(BSTree T, int key) {
    while (T != NULL && key != T->key) {
        if (key < T->key) T = T->lchild;
        else              T = T->rchild;
    }
    return T;
}

int BST_Insert(BSTree *T, int key) {
    if (*T == NULL) {
        *T = (BSTNode *)malloc(sizeof(BSTNode));
        (*T)->key = key;
        (*T)->lchild = (*T)->rchild = NULL;
        return 1;
    }
    if (key == (*T)->key) return 0;       // 不插入重复关键字
    if (key < (*T)->key) return BST_Insert(&(*T)->lchild, key);
    return BST_Insert(&(*T)->rchild, key);
}

// 删除：三种情况
BSTNode *BST_Delete(BSTree T, int key) {
    if (T == NULL) return NULL;

    if (key < T->key) {
        T->lchild = BST_Delete(T->lchild, key);
    } else if (key > T->key) {
        T->rchild = BST_Delete(T->rchild, key);
    } else {
        if (T->lchild == NULL) {          // 只有右孩子 / 叶子
            BSTNode *p = T->rchild;
            free(T);
            return p;
        }
        if (T->rchild == NULL) {          // 只有左孩子
            BSTNode *p = T->lchild;
            free(T);
            return p;
        }
        // 两个孩子：用右子树最小结点（中序后继）替代
        BSTNode *p = T->rchild;
        while (p->lchild != NULL) p = p->lchild;
        T->key = p->key;
        T->rchild = BST_Delete(T->rchild, p->key);
    }
    return T;
}
删除双子结点不是“随便接一个孩子”

要用中序前驱（左子树最大）或中序后继（右子树最小）替代被删结点，再删除那个替代结点，才能保持 BST 性质。

7.4AVL 树：让 BST 保持平衡

BST 的形状依赖插入顺序。若按 1,2,3,4,5 插入，会退化成一条右斜链，查找变 O(n)。 AVL 树通过限制左右子树高度差不超过 1，把树高控制在 O(log n)。

平衡因子 BF = 左子树高度 − 右子树高度 AVL 要求 |BF| ≤ 1

插入后若某个祖先的 |BF| 变成 2，就需要旋转。根据新结点插入的位置，分为 LL、RR、LR、RL 四种情况。

类型失衡原因操作
LL插入左孩子的左子树右单旋
RR插入右孩子的右子树左单旋
LR插入左孩子的右子树先左旋左孩子，再右旋根
RL插入右孩子的左子树先右旋右孩子，再左旋根
判断口诀

看“从失衡结点到新结点”的路径：前两步是“左左”就右旋，“右右”就左旋，“左右”就先左后右，“右左”就先右后左。旋转方向与路径方向相反。

AVL 的查找、插入、删除都是 O(log n)。代价是每次修改后可能要沿路径回溯更新高度并旋转， 适合查找远多于修改的场景。

7.5红黑树：更宽松的平衡

红黑树是另一种自平衡 BST。它不要求左右子树高度差不超过 1，而是用颜色约束保证 “最长路径不超过最短路径的 2 倍”，因此树高仍是 O(log n)，但旋转次数通常比 AVL 少。

AVL

  • 严格平衡，树更矮
  • 查找略快
  • 插入删除旋转更频繁
  • 适合读多写少

红黑树

  • 宽松平衡，树略高
  • 插入删除调整少
  • 工程实现广泛（map / set）
  • 适合读写混合

红黑树的插入删除调整涉及“变色”和“旋转”，规则较多。学习时先记住五条性质与“红红不相连”， 再理解插入后如何通过变色和旋转恢复性质，不必一开始就背完所有分支。

7.6B 树与 B+ 树：为磁盘而生

内存访问很快，磁盘 I/O 很慢。B 树把大量关键字放在一个结点里，让树变得“矮胖”， 从而减少磁盘读取次数。一个 m 阶 B 树满足：每个结点最多 m 个孩子、m−1 个关键字； 除根和叶外，每个非叶结点至少 ⌈m/2⌉ 个孩子（即至少 ⌈m/2⌉−1 个关键字）；所有叶子在同一层。

B+ 树是 B 树的变体：只有叶子结点存数据，内部结点只存索引； 所有叶子用链表连接。范围查询只需找到起点，再沿叶子链扫描，因此数据库索引更偏爱 B+ 树。

维度B 树B+ 树
数据存放所有结点都可存数据只有叶子存数据
叶子连接无叶子间有链表
范围查询需中序遍历沿叶子链扫描，快
单点查询可能在内部结点命中必须走到叶子
典型用途文件系统数据库索引

7.7哈希表：用函数直接定位

哈希表通过哈希函数 H(key) 把关键字映射到存储位置，理想情况下查找、插入、删除都是 O(1)。 难点在于冲突：不同的 key 可能算出同一个地址。

常见哈希函数

  • 除留余数法：H(key) = key mod p，p 通常取小于等于表长的最大质数。
  • 直接定址法：H(key) = a×key + b，适合关键字连续且范围小。
  • 数字分析法：选取关键字中分布较均匀的若干位。
  • 平方取中法：平方后取中间几位，让更多位参与结果。

冲突处理二：开放定址法

冲突时按某种探测序列找下一个空位。最简单的是线性探测：Hᵢ = (H(key)+i) mod m。 它容易产生“一次聚集”——连续被占用的区间越来越长，后续冲突概率更高。

hash.c / 拉链法插入与查找

#define M 11
typedef struct HashNode {
    int key;
    struct HashNode *next;
} HashNode;

HashNode *table[M];       // 每个桶的头指针

int Hash(int key) {
    return key % M;
}

void Insert(int key) {
    int h = Hash(key);
    HashNode *p = (HashNode *)malloc(sizeof(HashNode));
    p->key = key;
    p->next = table[h];   // 头插
    table[h] = p;
}

HashNode *Search(int key) {
    for (HashNode *p = table[Hash(key)]; p; p = p->next)
        if (p->key == key) return p;
    return NULL;
}
装填因子 α = 表中元素数 n / 表长 m α 越大，冲突越多；通常控制在 0.75 左右

哈希表的平均查找长度主要取决于装填因子，而不是 n 本身。拉链法在 α≈1 时平均成功查找约 1+α/2 次； 开放定址法对聚集更敏感。哈希表不保持元素顺序，也不支持范围查询。

排序：在混乱中建立次序

排序是数据结构里最“看得见”的算法。插入、交换、选择、归并、基数，每一种都在用不同的方式 减少逆序。理解它们的比较次数、移动次数、稳定性，比背代码更重要。

8.1排序的分类与稳定性

排序把一组记录按关键字递增或递减排列。按数据位置可分为内部排序（全部在内存） 和外部排序（数据太大，需要借助磁盘）。

稳定性是指：关键字相同的两个记录，排序前后的相对次序是否保持不变。 稳定排序在多关键字排序中很重要——先按次要关键字排，再按主要关键字排，稳定性能保留前一次的顺序。

稳定 ≠ 更快

稳定性是语义性质，不是性能指标。快排、堆排、选择排序都不稳定；插入、冒泡、归并、基数排序稳定。

8.2插入排序与希尔排序

直接插入排序把数组分成“已排序前缀”和“未排序后缀”。每次取后缀第一个元素 key， 在有序前缀中从后往前找位置，比 key 大的元素依次后移，最后把 key 放进去。

insertion.c / 直接插入排序

void InsertSort(int a[], int n) {
    for (int i = 1; i < n; i++) {
        int key = a[i];
        int j = i - 1;

        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];   // 大的元素后移
            j--;
        }
        a[j + 1] = key;
    }
}

插入排序稳定，空间 O(1)。它对基本有序的序列非常快，常被用作快排小区间的收尾优化。

希尔排序：先粗排，再细排

希尔排序按增量 gap 把序列分成若干子序列，分别做插入排序；逐步缩小 gap，最后 gap=1 时整体插入排序。 前期的大步长让元素快速接近最终位置，后期的小步长只需少量移动。

gap = n/2, n/4, …, 1 增量序列可以有多种取法，影响复杂度

希尔排序不稳定，时间复杂度依赖增量序列，通常优于 O(n²)，常见说法约 O(n^1.3)； 空间 O(1)。它是插入排序的“分组加速版”。

8.3冒泡排序与快速排序

冒泡排序

相邻元素两两比较，逆序就交换。每一趟把当前最大元素“冒”到末尾。若某一趟没有发生交换， 说明已经有序，可以提前结束。

bubble.c / 带提前退出的冒泡

void BubbleSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int swapped = 0;
        for (int j = 0; j < n - 1 - i; j++) {
            if (a[j] > a[j + 1]) {
                int t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
                swapped = 1;
            }
        }
        if (!swapped) break;   // 已经有序
    }
}

冒泡稳定，最好 O(n)，最坏 / 平均 O(n²)，空间 O(1)。

快速排序

快排选一个基准 pivot，通过一次划分把比它小的放左边、大的放右边，基准落到最终位置； 再递归处理左右两个子区间。它是所有内部排序中平均性能最好的之一。

quick.c / 划分与递归

int Partition(int a[], int low, int high) {
    int pivot = a[low];          // 取第一个元素为基准

    while (low < high) {
        while (low < high && a[high] >= pivot) high--;
        a[low] = a[high];        // 右边小的移到左边

        while (low < high && a[low] <= pivot) low++;
        a[high] = a[low];        // 左边大的移到右边
    }
    a[low] = pivot;
    return low;
}

void QuickSort(int a[], int low, int high) {
    if (low < high) {
        int pivotPos = Partition(a, low, high);
        QuickSort(a, low, pivotPos - 1);
        QuickSort(a, pivotPos + 1, high);
    }
}

快排平均 O(n log n)，最坏 O(n²)（每次基准都是最大或最小，划分极不平衡），不稳定， 递归栈平均 O(log n)、最坏 O(n)。随机基准或三数取中可以显著降低最坏情况概率。

快排不是“永远最快”

对已经有序的序列取首元素作基准，反而会退化成 O(n²)。工程实现通常会打乱、随机取基准或三数取中。

8.4选择排序与堆排序

简单选择排序每趟从未排序区间选出最小元素，与区间第一个位置交换。比较次数固定为 n(n−1)/2， 与初始序列无关；交换次数最多 n−1 次。它不稳定，时间 O(n²)，空间 O(1)。

堆排序：把数组看成一棵完全二叉树

大根堆满足每个父结点 ≥ 孩子。建堆后，堆顶是最大值；把它与末尾交换，堆大小减一， 再对堆顶做 sift-down，恢复堆性质。重复 n−1 次即得到升序。

heap.c / 建堆与堆排序

void SiftDown(int a[], int i, int n) {
    while (2 * i + 1 < n) {
        int child = 2 * i + 1;
        if (child + 1 < n && a[child + 1] > a[child])
            child++;                    // 选较大的孩子
        if (a[i] >= a[child]) break;
        int t = a[i]; a[i] = a[child]; a[child] = t;
        i = child;
    }
}

void HeapSort(int a[], int n) {
    for (int i = n / 2 - 1; i >= 0; i--)
        SiftDown(a, i, n);              // 建大根堆，O(n)

    for (int end = n - 1; end > 0; end--) {
        int t = a[0]; a[0] = a[end]; a[end] = t;
        SiftDown(a, 0, end);            // 恢复堆，O(log n)
    }
}

堆排序最好、最坏、平均都是 O(n log n)，空间 O(1)，不稳定。 它适合对最坏情况有要求、又不希望额外空间的场景，例如实时系统。

8.5归并、计数与基数排序

归并排序

归并排序把序列二分到只有一个元素，再两两合并。合并时比较两个有序子序列的队头， 较小者先放入辅助数组。它是典型的分治算法。

归并排序适合链表（不需要随机访问）、外部排序（可以分块归并）以及要求稳定且能接受额外空间的场景。

计数排序

当关键字是范围不大的整数时，统计每个值出现次数，再按值从小到大输出。 时间 O(n+k)，空间 O(k)，k 为值域。它不是比较排序，不受 O(n log n) 下界限制。

基数排序

基数排序按位处理：先按个位分桶收集，再按十位、百位……直到最高位。每一趟分配和收集都是稳定的， 所以最终结果有序。

T(n) = O(d(n+r)) d 位数，r 基数（十进制为 10）

基数排序稳定，适合位数少、范围可控的整数或定长字符串。它需要额外的桶空间 O(n+r)， 且不能直接处理负数和浮点数（需要额外映射）。

8.6外部排序：数据装不进内存怎么办

外部排序处理的是“比内存还大”的文件。基本流程是：先把文件分成若干块，每块读入内存排序， 写回磁盘形成初始归并段；然后对这些归并段做多路归并，逐步合并成一个有序文件。

外部排序的瓶颈是磁盘 I/O，不是比较次数。增加归并路数 k 可以减少归并趟数： 归并趟数约为 ⌈logk m⌉（m 为初始归并段数）。但 k 太大，内存中要同时维护 k 个输入缓冲区， 且每次选最小值的开销增加。

败者树

在多路归并中，用败者树（或优先队列）在 k 个当前元素中快速选出最小值，把每次选择的比较次数从 O(k) 降到 O(log k)，从而减少总比较开销。

还有“置换-选择排序”可以生成长度不等的初始归并段，再配合哈夫曼思想做最佳归并， 减少读写次数。这些属于外部排序的进阶优化。

}

int TreeHeight(BiTree T) {
    if (T == NULL) return 0;

    int rh = TreeHeight(T->rchild);
    return (lh > rh ? lh : rh) + 1;
}

int Find(int parent[], int x) {

next 由模式串自身的最长公共前后缀得到，失配时据此决定模式串的新起点，避免主串回退。

9.5补充：多维数组、矩阵压缩与广义表

线性表并不只限于“一列元素”。多维数组可以看作线性表的推广，特殊矩阵和稀疏矩阵则利用数据的规律 来减少存储。广义表更进一步：它的元素既可以是原子，也可以是一张表，因此能表示嵌套结构。

多维数组与矩阵压缩

二维数组在内存中通常按行优先展开：先存第 0 行，再存第 1 行…… 因此 a[i][j] 的地址可以用“行偏移 × 列数 + 列偏移”直接算出。

类型存储策略空间典型映射
二维数组行优先 / 列优先连续存放m×n行优先：k = i×n + j
对称矩阵只存下三角（含对角线）n(n+1)/2k = i(i+1)/2 + j（i≥j）
三角矩阵只存上 / 下三角 + 一个常数n(n+1)/2 + 1按行展开

稀疏矩阵三元组表 / 十字链表与非零元个数有关(行, 列, 值)
行优先与列优先

C 语言的多维数组按行优先存储。若题目给出“列优先”，地址公式要改成 j×m + i，考试中必须先看清题目约定。

广义表：表中套表

广义表 LS 的元素可以是单个元素（原子），也可以是一个子表。例如 LS = (a, (b, c), (d, (e)))，它的长度是 3，深度是 3。 表头 GetHead 取第一个元素，表尾 GetTail 去掉表头后剩下的表（注意结果仍然是表）。

表头与表尾

GetHead(LS) = a；GetTail(LS) = ((b,c), (d,(e)))。注意 GetTail 的结果是“去掉表头后的表”，不是单个元素。

广义表常用于 Lisp 风格的嵌套数据、表达式表示、文件目录等。它的递归定义让“表”可以无限嵌套， 但实现时需要区分原子结点和表结点，通常用 tag 标志位。

9.6结课寄语

数据结构不是一堆需要背下来的名词，而是一套关于“如何组织关系、如何付出代价”的思维方式。 当你能在看到问题时先问“数据之间是什么关系、最常做什么操作、最坏情况能否接受”， 这门课就真正变成你的能力了。
